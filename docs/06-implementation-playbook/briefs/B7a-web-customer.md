## Deliverables

### Foundation (shared with B7b)
- Vite config (dev proxy `/api` → `http://localhost:8787`, build to `apps/web/dist`), `index.html` with `lang="fa" dir="rtl"`, PWA basics (manifest, theme-color, offline fallback page), **performance budget** (JS ≤ 250 kB gz initial; route-level code splitting; images lazy), no external network calls at runtime except the API and the Mini App host script.
- **Design system** (`src/ui/`): tokens (from `design-tokens.json` when present; light + dark), typography (Vazirmatn, Persian numerals), components: Button, IconButton, Input (currency/amount/phone/OTP variants), Select, Segmented, Tabs, Card, Badge (risk label colours), Alert/Banner, Modal/Sheet (bottom sheet in Mini App), Toast, Skeleton, Stepper/Timeline, CopyField (copy-to-clipboard with feedback), Countdown (price-lock), PriceBreakdown (itemised lines, expandable), Table (responsive), EmptyState, ErrorBoundary. All keyboard-accessible, focus-visible, ARIA-correct; contrast AA.
- **i18n/copy**: all strings from `src/copy/fa.ts` generated from `data/copy.fa.json` (+ typed keys); no hard-coded UI text in components. Formatters from `@hiclaude/contracts` (Toman, USD, USDT, Jalali dates, durations).
- **API client** (`src/api/`): typed fetch wrapper (`credentials: 'include'`, CSRF header, error → `ApiError` with Persian message), TanStack Query hooks per endpoint, SSE hook for order streams with backoff, idempotency keys for money-moving calls.
- **Auth**: OTP login sheet (phone → code → session), session bootstrap (`/me`), logout, referral code capture from URL, guarded routes.
- **Host abstraction** (`src/host/`): `MessengerHost` with adapters for Telegram WebApp, Bale WebApp and none; theme sync, safe-area/viewport, BackButton/MainButton integration, haptics, `initData` auth call, deep links (`startapp`), share/referral. A **simulated host** for demo/E2E (`?host=telegram|bale` + stub object) so Mini App flows are testable in Chromium. Mini App routes under `/tg/*` and `/bale/*` reuse the same pages with host-aware chrome.

### Customer pages (mobile-first, desktop-friendly)
1. **Home** — live **rate board** (our indicative USD price, change, status; updates via polling/SSE), value props, trust block, how-it-works, featured products, SLA/rush explainer, FAQ, footer with legal links, demo banner.
2. **Catalog** — categories/search/filters, product cards with live "from" price, **risk badge + restriction note** (mandatory), SLA.
3. **Product page + live calculator** — amount selection per `AmountSpec`, required inputs per product, rush tier selector with availability/ETA/premium, **instant quote** (debounced) with itemised breakdown (transparent lines; hide internal buffers only if the UX spec says so but totals always reconcile), per-payment-method totals (incl. USDT-pay discount message), **price-lock countdown** with auto re-quote and a clear "price changed" diff state, honest comparison note when `savingsVsMarketPct` present, warnings, risk acknowledgement checkbox for high-risk products (blocks checkout until ticked).
4. **Checkout** — payment method choice; per-method instruction screens: gateway redirect, **card-to-card** (copyable card number & exact amount, receipt form with tracking no./last-4/time + optional image upload with client-side compression), bank transfer, **USDT** (network chooser, address QR (inline SVG QR generator, no deps or a tiny lib), exact amount, memo, confirmations progress), wallet. Expiry countdown, late-payment explanation, support shortcut.
5. **Order tracking** — timeline (Persian labels), live status via SSE, ETA/SLA, payment status, actions (cancel / confirm / dispute), **secure reveal** for card/voucher (OTP step-up, one-time view, auto-hide timer, copy buttons, masked by default), receipt/invoice view, refund status.
6. **Orders list**, **Wallet** (balance, top-up), **Profile & KYC** (limits/tier explainer), **Referral** (code, share via host), **Support** (tickets + FAQ), **Legal pages** (terms, privacy, refund, risk disclosure — render markdown from `docs/08-compliance-risk/templates/*.fa.md` when present at build time, else placeholders).
7. **System states**: kill-switch banner, rates-stale banner, maintenance, offline, 404, error boundary, session expired.
