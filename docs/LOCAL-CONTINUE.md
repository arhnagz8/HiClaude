# ادامه‌ی پروژه به‌صورت لوکال (Local continuation guide)

آخرین به‌روزرسانی: 2026-10-03 · شاخه: `claude/epic-einstein-mw1ohs` · مخزن: `arhnagz8/HiClaude`
همه‌ی نتایج تحقیق، کد نیمه‌کاره، بریف‌ها و اسکریپت‌ها داخل همین مخزن commit شده‌اند. **چیزی فقط در حافظه‌ی جلسه نیست** (خلاصه‌ی خروجی ایجنت‌ها هم در `docs/03-research/_summaries/` ذخیره شده است).

## 1) راه‌اندازی لوکال (۵ دقیقه)
```bash
git clone https://github.com/arhnagz8/HiClaude && cd HiClaude
git checkout claude/epic-einstein-mw1ohs
node -v            # باید >= 22.13 باشد (node:sqlite داخلی است؛ چیزی نیاز به build ندارد)
npm install
npm run typecheck  # تایپ‌چک همه‌ی workspaceها
npm test           # vitest روی همه‌ی پکیج‌ها
npm run validate:data   # اعتبارسنجی فایل‌های data/*.json (Recordها با as_of/confidence/sources)
```
برای کار با Claude Code لوکال: داخل پوشه‌ی پروژه `claude` را اجرا کنید؛ ابتدا `CLAUDE.md` (قانون‌نامه‌ی پروژه) و `docs/MISSION.md` + `docs/STATUS.md` را بخواند.

## 2) پروژه چیست؟
پلتفرم white-label فارسی/RTL برای فروش کارت مجازی، شارژ کارت، گیفت‌کارت و پرداخت سرویس‌ها: مشتری تومان می‌دهد (درگاه / کارت‌به‌کارت / انتقال بانکی / تتر)، مالک تتر را از صرافی داخلی تهیه و به تأمین‌کننده منتقل می‌کند. قیمت‌ها کاملاً داینامیک‌اند (نرخ تتر، کارمزد صرافی/تأمین‌کننده، بافر نوسان، سرعت (rush)، کارمزد روش پرداخت، مالیات، رقبا). علاوه بر محصول، یک **شبیه‌ساز دنیای واقعی** (ماکرو/نرخ، صرافی، بانک، درگاه، زنجیره، تأمین‌کننده، رقبا، مشتریان، اپراتورها، مالک) طراحی شده که همان کد واقعی را سال‌ها اجرا می‌کند و صورت‌های مالی را از دفتر کل دوطرفه می‌دهد.
معماری: `docs/05-architecture/architecture.md` (+ `sim-spec.md`, `api-spec.md`, `ux-spec.md`).

## 5) یافته‌های کلیدی تحقیق (تا اینجا)
1. **سقف واریز شناسه‌دار ۲۵ میلیون تومان در ۲۴ ساعت برای هر کد ملی ≈ ۹۷ تتر در روز** عملاً گلوگاه اصلی ظرفیت است؛ هدف ۳۰ سفارش ۱۰۰دلاری در روز با یک حساب شدنی نیست. مسیرهای قانونی: حساب کسب‌وکار/OTC، سطح KYC بالاتر، شرکای واقعی با رضایت و ثبت قانونی (نه تقسیم پرداخت یا هویت قرضی).
2. **قفل ۷۲ ساعته‌ی برداشت رمزارز پس از واریز تومانی** ⇒ فلوت تتر از قبل لازم است (فرمول و جدول در سند ۰۲).
3. **تحریم OFAC** (۲۰۲۶-۰۶-۰۲) چهار صرافی نوبیتکس/والکس/بیت‌پین/رمزینکس را شامل می‌شود (تأییدشده با منابع متعدد)؛ Tether حدود ۵۵۰ میلیون دلار USDT مرتبط با ایران را فریز کرده ⇒ ریسک جدی برای زنجیره‌ی تتر. تحلیل در سند ۰۵.
4. **توقف شبانه‌ی تتر ۲۱–۰۹ و سقف خرید ۲٬۰۰۰ تتر/روز** فقط موقت (۲۰۲۶-۰۹-۳۰ تا ۱۰-۰۴) بود؛ احتمال تکرار.
5. **mpay**: API/پارتنر عمومی پیدا نشد؛ ریویوهای منفی (از دست رفتن موجودی)؛ کارمزد شارژ منتشر نشده (در مدل ۳٪ فرض شده، UNVERIFIED) ⇒ ریسک طرف‌حساب بالا؛ فلوت را حداقلی نگه دارید و تأمین‌کننده‌ی جایگزین داشته باشید.
6. **رقبا:** نقطه‌ی سربه‌سر مدل ما ≈ +۶٫۹۵٪ بالای دلار آزاد برای شارژ ۱۰۰ دلاری، در حالی که کارمزد ظاهری رقبا ۴–۶٪ است ⇒ قبل از قیمت‌گذاری باید قیمت‌های هم‌روز رقبا را مستقیم گرفت (پروتکل mystery-shopper در سند ۰۷).
7. **مالیات:** ارزش افزوده ۱۰٪ (متوسط‌اعتماد)، مالیات شرکت ۲۵٪؛ کسر VAT از قیمت ثابت حدود ۶۷٪ سود هر سفارش را می‌خورد؛ مالیات بر بهای تمام‌شده‌ی تاریخی در افت ارزش سنگین است.
9. **حقوقی:** فروش ارز/تتر بدون مجوز ریسک «صرافی غیرمجاز» دارد؛ محصول باید «خدمات دیجیتال» ساختاربندی شود؛ مشاوره‌ی وکیل (گیت G1) قبل از لانچ ضروری است. استفاده از چند کد ملی برای دور زدن سقف **در پروژه ممنوع** است (CLAUDE.md §3) — بخش مربوطه در `docs/business-plan-full-context.md` باید با جایگزین قانونی اصلاح شود.

## 6) ادامه‌ی کار — ترتیب پیشنهادی
1. `git pull`، `npm install`، `npm test` و بررسی اینکه `packages/core` و `packages/sim` تایپ‌چک/تست سبز دارند (در صورت قرمز بودن، بریف مربوطه را دوباره با Claude Code اجرا کنید).
2. تکمیل تحقیق‌های ناقص (۰۸، ۰۹، ۰۱۰) و سپس ۱۲ و بازبینی/راستی‌آزمایی (هر بریف در `docs/03-research/_briefs/`، اسکریپت `scripts/workflows/research.js`). اگر Workflow tool ندارید، هر بریف را مستقیم به Claude Code بدهید: «`CLAUDE.md` و بریف X را بخوان و کامل اجرا کن».
3. **B3** (موتور app) → **B5b** (یکپارچه‌سازی شبیه‌ساز و اجرای ۳ ساله + ۱۵ سناریو) → **B6** (API) → **B7a/B7b** (وب/ادمین) → **B10** (کالیبراسیون) → **B8** (آداپتورهای live) → **B9** (تست پرسونا).
4. حلقه‌ی دیبیت (`scripts/workflows/debate.js`) و بازبینی مالک (`owner-review-loop.js`)، سپس `docs/00-START-HERE.md` و مسیر مالک (`docs/01-owner-journey/_brief.md`).
هر بریف مستقل است: ورودی‌ها، خروجی‌ها، تست‌ها و معیار پذیرش دارد. قاعده‌ی کار موازی: فقط فایل‌های حوزه‌ی خودتان را ویرایش کنید؛ commit را مرکزی انجام دهید.

## 7) نکات فنی مهم
- Node ≥ 22.13، `node:sqlite` (هشدار Experimental طبیعی است). نصب هم‌زمان npm: `flock /tmp/hiclaude-npm.lock npm install …`.
- پول همه‌جا عدد صحیح (Toman / micro-USDT / cents)، زمان فقط از `Clock`، تصادف فقط از `Rng` (قطعی بودن شبیه‌ساز).
- `data/*.json` رکوردهای provenance دارند (`value/as_of/confidence/sources/verify_how`)؛ `data/sim/*` و `data/config/*` مقادیر ساده‌ی اجرایی‌اند (اعتبارسنج آن‌ها را نادیده می‌گیرد).
- Playwright: از Chromium سیستم (`/opt/pw-browsers/chromium`) با `executablePath` استفاده شود؛ `playwright install` نزنید.
- `docs/business-plan-full-context.md` سند دور اول است؛ ارقام آن با تحقیق‌های بعدی (به‌ویژه ۰۲/۰۴/۰۵/۰۷) اصلاح می‌شوند.
